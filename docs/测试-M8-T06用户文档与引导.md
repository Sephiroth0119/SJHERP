## 本地如何验

1. 启动后端与 `web/` 开发服务，用 **admin** 登录（清掉该用户的 `localStorage` 键 `sjherp.onboarding.status.<用户名>`）。
2. 应弹出「新手引导：建档案 → 期初 → 第一张单」。
3. 填写真实单位/仓库/商品/供应商名称（不要用空名称点保存），保存档案。
4. 登记期初数量与单价，确认库存台账出现 OPENING 流水。
5. 填写采购数量与单价，得到一张 **DRAFT** 采购订单；到采购工作台能打开，且尚未审核。
6. 点「稍后再说」后刷新不再自动弹出；顶栏「新手引导」或 **帮助 → 打开新手引导** 可再打开。
7. 用无 `purchase:order` 的账号登录：向导不出现「第一张单」提交。
8. `git diff --stat -- web-dist` 相对 main 为空。

无浏览器工具时，以上第 3–5 步由 `onboarding.test.js` 的 fetch 契约覆盖；第 6–7 步由存储与权限单测覆盖。
