## 验收范围

- JSON + Ed25519 license：签发对象、签发日、可选到期日 / 席位 / 模块开关、签名
- 运行时：启动加载 + 定时/按请求重读；状态 有效 / 未配置 / 宽限 / 过期 / 签名无效 / 无法解析
- 未配置不挡业务；`SJHERP_LICENSE_ENFORCE=true` 才对过期/坏签名硬阻断
- `deploy/license.sh --check` 解析样例并验签；`.env.example` 有变量、无真实生产密钥
- `GET /api/license/status` 仅 ADMIN/BOSS（`license:view`）
- 帮助页只读展示；无支付 UI
- 测试覆盖校验、过期、坏签名、未配置

## 本地如何验

```bash
chmod +x deploy/license.sh
./deploy/license.sh --check
git diff --stat -- web-dist   # 应无输出
```

聚焦后端：

```bash
cd server
mvn -B -ntp test -pl sjherp-domain -Dtest=RolePermissionsTest
mvn -B -ntp test -pl sjherp-app -Dtest=LicenseEvaluatorTest,LicenseServiceTest,LicenseEnforceFilterTest,LicenseApiPermissionTest,LicenseCliTest
```

前端：`cd web && npm test`

签发一张本地文件（测试密钥）：

```bash
./deploy/license.sh --issue --subject "本地试点" --expires 2027-10-23 --out /tmp/sjherp.license.json
./deploy/license.sh --verify --file /tmp/sjherp.license.json
```

有 Docker 的栈：把文件拷到 `deploy/license/sjherp.license.json`，重启 app，ADMIN 打开「帮助」应看到签发对象与到期日。不要打开 `SJHERP_LICENSE_ENFORCE` 除非要演练硬阻断。
