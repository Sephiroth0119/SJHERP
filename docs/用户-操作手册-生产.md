# 操作手册 — 生产

小企业生产按这条线走：**BOM / 工艺 → 需求计划与 MRP → 工单 → 领料 → 报工完工 → 成本结转**。

菜单：左侧 **生产**。各页签需要对应 `production:*` 权限，通常是管理员或老板；成本结转会计也可以做。

## 基础：BOM 与工艺路线

1. 先有产成品和子件的商品档案。
2. 维护物料清单（父件 + 子件用量 + 损耗率）。损耗按加成：毛用量 = 净用量 × (1 + 损耗率)。
3. 同一产品同时只能有一个启用版本。
4. 工艺路线登记工序顺序和工时，费率给月末成本归集用，可以先空着。

系统会拦 BOM 环（A 用 B、B 又用回 A）。

## 计划与 MRP

1. 录入需求计划（预测），销售订单的需求运行时自动汇总，不必再抄一遍。
2. 跑 MRP：有启用 BOM 的出生产建议，叶子件出采购建议。
3. 建议是这一次运算的结果，改完档案或订单后请重新跑，不要手工改建议去当库存。

## 工单

1. 可手工建，也可从 MRP 生产建议转单。
2. 状态：草稿 → 下达（审核）→ 开工 → 完工。投产后不能当没发生过直接冲掉。
3. 下达后才能领料；开工后才能报工。

## 领料 / 退料 / 齐套

1. 领料单选工单和领料仓，过账才扣原材料库存。库存不够整单回滚。
2. 齐套检查只提示缺料，不预留、不拦下工单。
3. 退料必须对着原来的领料单，按原领料成本退回，不能退超过已领数量。

## 报工与完工入库

1. 报工单同时记工时和完工数量。过账后产成品入库。
2. 本阶段入库成本按工单已领净料费结转，保证「领出去的料」和「入进来的成品料费」对得上。
3. 工单不会因为报工就自动关掉，是否完工由你点。

## 成本结转

月末按工单归集料、工、费，在产用约当产量。完工工费追加到产成品成本，不破坏库存数量恒等式。必须在关账之前做。详见 [生产成本核算规则.md](./生产成本核算规则.md)。
