## 契约与权限

真实路径为 `/api/partner/suppliers` 和 `/api/warehouse/warehouses`。创建权限分别为 `partner:create_supplier`、`warehouse:create_warehouse`；维护权限分别为 `partner:write`、`warehouse:write`。查询沿用登录态，前端权限判断 fail-closed，后端负责最终授权。

API 层通过窄映射移除运行时对象中的 id/status/audit 字段；仓库 `locationEnabled` 精确保持 boolean。状态动作使用真实 enable/disable REST 路径。
