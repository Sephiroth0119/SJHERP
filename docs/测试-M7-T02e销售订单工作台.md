# M7-T02e 销售订单工作台测试与验收记录

## 当前状态

T02e 已实现待验收（2026-07-26）。本地测试与前端生产构建已通过；尚未创建 PR，GitHub 前端、后端与 MySQL 8.4 CI 尚未运行。M7-T02 整体仍进行中，T02f–T02g 待后续。

## 验收范围

- 销售模块保留 T02a 客户档案，并增加“客户档案 / 销售订单”二级切换。
- 销售订单仅调用真实分页、详情、创建、审核、作废端点。
- 客户与商品使用真实分页搜索和可读编码/名称选择，不要求输入裸 ID。
- 名称补载失败时明确显示带引用 ID 的“名称不可用”，不长期伪装成加载中。
- 创建请求窄化为 `customerId/orderDate/remark/lines[productId/quantity/unitPrice]`，不发送可选 `checkWarehouseId` 或其他运行时字段。
- 数量、单价、金额、已发货量和剩余可发量均按字符串承载，无 JavaScript 浮点换算。
- 创建、审核、作废共享同步 in-flight 守卫，快速双击不会重复发送业务写请求。
- 仅 `sales:order` 持有者可见订单页签与订单动作；后端类级权限仍是最终边界。
- 不提供编辑、删除、关闭、冲销、销售出库或销售发票动作。

## 本地验证

- `npm.cmd test`：37 项通过。其中新增 8 项覆盖：
  - `customerId/status/page/size` 精确查询参数与详情路径；
  - 查询、详情与创建 mutation 响应为 JSON number 时，数量、单价、金额、已发和未发数量仍统一归一为字符串；
  - 创建时传入多余字段，证明只透传精确窄请求体，并正确解包 `{ order, warnings }`；
  - 审核与作废使用精确 URL 和 `POST`；
  - 调用轨迹无 `DELETE`，API 与界面无虚构编辑、删除、关闭、冲销动作；
  - 数量正数、单价非负、至少一行和商品不重复边界；
  - 订单页签严格由 `permissions.includes('sales:order')` fail-closed 控制；
  - 创建与状态流转共享同步 in-flight 守卫，并在 `finally` 释放。
  - 列表、详情、客户与商品引用请求均具备版本隔离，同条件重查通过刷新键再次发起请求；按钮 `type`、错误 `role="alert"` 和成功 `role="status"` 保持可访问反馈。
- `npm.cmd run build`：TypeScript 检查与 Vite production build 通过。
- `git diff --check`：通过。
