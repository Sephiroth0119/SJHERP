# 操作手册 — 采购

采购分三张单：**订单 → 入库 → 发票**，最后用付款单核销应付。

菜单：左侧 **采购**。没有某个页签，就是当前账号没有对应权限。

## 采购订单（采购 → 采购订单）

1. 点 **新建采购订单**，选供应商，填下单日期。
2. 每一行选商品、数量（必须大于 0）、单价（可以是 0）。同一商品不要在一张单里出现两行。
3. 保存后是**草稿**。核对无误再 **审核**。
4. 下单 **不会增加库存**。货还没到。
5. 不再收货时 **关闭**。草稿可作废。

权限：`purchase:order`（管理员 / 老板 / 采购）。

## 采购入库（采购 → 采购入库）

1. 选一张**已审核、还没收完**的采购订单，再选收货仓库和日期。
2. 填写本次实收数量，可以少于订单量（分批到货）。超过未收量会被拒绝。
3. 保存草稿 → 审核 → **过账**。过账后库存增加，订单行的已收量同时增加。
4. 库存不够回滚整张单，不会出现「库存进了、订单还显示没到」。

权限：`purchase:receipt`（管理员 / 老板 / 仓管）。没有采购订单权限的仓管，仍可在入库页看到「可收货订单」列表。

## 采购发票（采购 → 采购发票）

1. 选一张**已过账、还没开完票**的入库单。
2. 开票数量不能超过已收量（跨多张发票累计计算）。
3. 审核后过账：生成**应付账款**，并自动出凭证。过账前界面会二次确认。

权限：`purchase:invoice`（管理员 / 老板 / 会计）。

## 付款（采购 → 付款）

应付产生之后，用付款单按供应商分摊核销，过账才动账、才出现金凭证。详见 [用户-操作手册-财务.md](./用户-操作手册-财务.md)。

## 不要做的事

- 不要把入库当成「改库存数字」。入库必须挂订单。
- 已过账单据不能删除。要冲销请走冲销（高风险，工作台默认不暴露，需有权限的人在 Agent 或后端入口处理）。
- 向导里的「第一张单」只创建订单草稿，记得回来审核。
