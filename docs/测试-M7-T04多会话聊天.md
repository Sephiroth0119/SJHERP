## 验收范围

- 多会话：登录用户可新建、切换会话；会话 `user_id` 归属当前登录用户。越权读/写/重命名/归档/发消息一律按「不存在」返回 **404**（不用 403，避免泄露会话存在性）。ADMIN 不豁免。
- 历史列表：`GET /api/chat/sessions` 只返回本人摘要（`sessionId/title/status/createdAt/updatedAt`），按 `updatedAt` 降序，**不加载消息正文**。侧栏展示标题（空则「新会话」）与最近更新时间；点击打开历史。
- 重命名 / 归档：`PUT /api/chat/sessions/{id}/title`、`POST /api/chat/sessions/{id}/archive`。归档将 `status` 置为 `CLOSED`，**无物理删除、无 DELETE 入口**。已归档会话只读，发消息 **409**，错误文案展示后端原文。
- 单据卡片：AgentReply v0.1 **加性**可选字段 `documents[]`（`type` + `docNo` + 可选 `title`）。前端按权限 fail-closed 渲染可点击卡片，hash 跳转传统工作台详情（`#/{module}/{tab}/{docNo}`）；无权限不渲染、不跳转、不补拉详情。卡片只展示类型中文名与单号，不附带金额/数量。
- 工具回填：后端从本轮成功工具结果的 `data.docNo` / `data.doc_no` 提取单据引用，与模型声明合并、按 type+docNo 去重；失败/未知工具/无单号跳过，不编造。
- 协议版本仍为 `0.1`；空 `documents` 序列化时省略。流式分片仍留给 M7-T03 的 v0.2。

## API 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/chat/sessions` | 新建，201 `{sessionId, createdAt}` |
| GET | `/api/chat/sessions` | 本人列表 `{items:[...]}` |
| GET | `/api/chat/sessions/{id}` | 详情（含 title/status/messages）；非本人/不存在 404 `{error}` |
| PUT | `/api/chat/sessions/{id}/title` | 重命名；空标题 400；非本人 404 |
| POST | `/api/chat/sessions/{id}/archive` | 归档 CLOSED，幂等；非本人 404 |
| POST | `/api/chat/sessions/{id}/messages` | 发消息，响应 AgentReply；已归档 409；非本人 404 |
