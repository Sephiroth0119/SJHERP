# 操作手册 — 基础档案

档案是后面所有单据的基础。没有商品、仓库、客户、供应商，订单和库存都建不起来。

## 谁能新建

| 档案 | 菜单 | 新建权限（常见角色） |
|---|---|---|
| 客户 | 销售 → 客户档案 | `partner:create_customer`（管理员 / 老板 / 销售） |
| 供应商 | 采购 → 供应商档案 | `partner:create_supplier`（管理员 / 老板 / 采购） |
| 仓库 | 库存 → 仓库档案 | `warehouse:create_warehouse`（管理员 / 老板 / 仓管） |
| 商品 / 单位 / 类目 | 库存 → 商品档案 | 商品 `catalog:create_product`；单位和类目 `catalog:write` |

改名称、启停一般还要对应的 `*:write` 权限。没有按钮就是没权限，不要找「隐藏删除」。

## 客户 / 供应商

1. 打开对应档案页，点 **新建**。
2. **名称**和**结算方式**必填：月结 / 现结 / 预付。编码可留空，系统自动编号。
3. 客户可填信用额度（字符串，空表示不设）。
4. 保存后可在详情里启停。停用后不要再拿来开新单。

## 仓库

1. 库存 → 仓库档案 → 新建。
2. 至少要有一个**启用**仓库：期初、采购入库、销售出库、领料都要用。
3. 库位开关可先关掉，小企业用不到再开。

## 单位、类目、商品

1. 先建 **单位**（如「个」，小数位 0～6）。商品的基本单位必须先存在。
2. 类目可选。没有类目也能建商品。
3. 新建商品：名称、**存货分类**（原材料 / 半成品 / 产成品 / 商品）、基本单位必填。
4. 多单位换算按字符串填，大于 0；基本单位本身不用再登换算率。

## 建议顺序

第一次建账：单位 → 仓库 → 商品 → 供应商 → 客户。也可以直接走登录后的新手向导，向导调用的就是这些接口。

大批量已有资料用 Excel 导入，见 [业务-期初导入.md](./业务-期初导入.md)。导入是整批成功或整批失败，不会留下半截名单。
