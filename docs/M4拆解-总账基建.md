# M4-T01 总账基建 拆解与实现方案

> 路线图 §6 M4-T01（L 级，全系统最高风险的财务核心）。本文是 T01 的单一设计真源，实现严格据此。
> 范围：科目表（预置小企业会计准则模板）+ 凭证（借贷分录，**保存即校验平衡**）+ 账期管理（开启/关闭，**关账后禁止过账**）。
> **不做**：自动凭证生成（T02）、月末结转/试算结账（T05）、红字冲销实现（T07）、财务 Agent 工具（T08）——但留好扩展点。

## 0. 验收硬标准映射
- **①不平凭证无法保存** → `Voucher.create(...)` 构造工厂强制借贷平衡不变式，不平抛 `VoucherNotBalancedException`，聚合都构造不出，到不了 `repository.save`。
- **②关账期过账被拒** → `VoucherService.post` 先校验所属账期 `OPEN`，否则抛 `PeriodClosedException`；集成测试真库验证（关账→再过账被拒+事务回滚）。

新建领域包 **`com.sjherp.domain.gl`**（general ledger）。

## 1. 数据库迁移 V19（`V19__general_ledger.sql`）
沿用现有风格：utf8mb4、DATETIME(6) 按 UTC、金额 DECIMAL(18,2)、tenant_id BIGINT NOT NULL DEFAULT 0 纳入唯一键最左前缀（应用层恒 0）。

### account（科目表）
字段：id、tenant_id、`code VARCHAR(32)`（科目编码，租户内唯一）、`name VARCHAR(100)`、`account_type VARCHAR(16)`（ASSET/LIABILITY/EQUITY/COST/PROFIT_LOSS）、`balance_dir VARCHAR(8)`（DEBIT/CREDIT）、`parent_code VARCHAR(32) NULL`（树形自关联，按编码）、`level TINYINT`、`is_leaf TINYINT(1)`（仅末级可挂凭证行）、`enabled TINYINT(1) DEFAULT 1`、`is_preset TINYINT(1) DEFAULT 0`（预置科目禁停用/改类别）、审计四字段。
键：`UNIQUE KEY uk_account_code(tenant_id, code)`、`KEY idx_account_parent(tenant_id, parent_code)`、`KEY idx_account_type(tenant_id, account_type, code)`。

### accounting_period（会计期间）
账期业务键 **`period CHAR(6)` = yyyyMM**（与凭证号年月段、doc_sequence scope_key 对齐）；冗余 `period_year SMALLINT`/`period_month TINYINT` 供报表聚合。字段还有 `status VARCHAR(8)`（OPEN/CLOSED）、`closed_by VARCHAR(64) NULL`、`closed_at DATETIME(6) NULL`、审计四字段。`UNIQUE KEY uk_period(tenant_id, period)`。账期不走单据状态机（OPEN/CLOSED 两态档案）。

### voucher（凭证头，继承 BusinessDocument 故含其全部字段）
id、tenant_id、`doc_no VARCHAR(64)`（VCH-yyyyMM-序号，租户内唯一）、`period CHAR(6)`、`voucher_date DATE`、`word VARCHAR(8) DEFAULT '记'`、`total_amount DECIMAL(18,2)`（Σ借=Σ贷，落库前已校验）、`summary VARCHAR(255) NULL`、`source_doc_no VARCHAR(64) NULL`、`source_doc_type VARCHAR(32) NULL`（T02 回填，T01 为 NULL）、`status VARCHAR(16)`、`reversal_of_id`/`reversed_by_id VARCHAR(64) NULL`、审计四字段。
键：`uk_voucher_doc_no(tenant_id, doc_no)`、`idx_voucher_period(tenant_id, period, id)`、`idx_voucher_source(tenant_id, source_doc_no)`、`idx_voucher_status(tenant_id, status, id)`。

### voucher_line（凭证行）
id、tenant_id、`voucher_id BIGINT UNSIGNED`、`line_no INT`、`account_code VARCHAR(32)`（须末级）、`debit DECIMAL(18,2) DEFAULT 0`、`credit DECIMAL(18,2) DEFAULT 0`、`summary VARCHAR(255) NULL`。
键：`uk_voucher_line(tenant_id, voucher_id, line_no)`、`idx_voucher_line_head(voucher_id, line_no)`、`idx_voucher_line_account(tenant_id, account_code)`（科目余额/试算平衡派生聚合用）。

## 3. 领域层（`com.sjherp.domain.gl`）
### 枚举
- `AccountType`：ASSET/LIABILITY/EQUITY/COST/PROFIT_LOSS（各带中文 label）。
- `BalanceDirection`：DEBIT/CREDIT（label 借/贷）。
- `PeriodStatus`：OPEN/CLOSED。

### Account（档案聚合，实现 AuditTarget，不继承 BusinessDocument，参照 product 两态档案）
字段 code/name/type/balanceDir/parentCode/level/isLeaf/enabled/isPreset + 审计。`create(...)` 工厂校验非空、level≥1；`disable()`/`enable()`（预置科目 disable 抛拒绝）；`assignId`；`restore` 工厂；`auditSummary` 出编码/名称/类别。

### AccountingPeriod（实现 AuditTarget，不走单据状态机）
字段 period/year/month/status/closedBy/closedAt + 审计。`open(period, operator)` 工厂（OPEN）；`close(operator)`（OPEN→CLOSED，记 closedBy/At；已 CLOSED 再关抛 IllegalStateException）；`reopen(operator)`（CLOSED→OPEN，高敏）；不变式 period 匹配 `\d{6}`、month 1-12。

### Voucher（继承 BusinessDocument）+ VoucherLine + 平衡不变式
**状态映射**：DRAFT=草稿、APPROVED=已过账、REVERSED=已冲销、CANCELLED=草稿作废。过账走 `DRAFT→APPROVED` 一步流转。Voucher 提供语义方法 `post(operator)` 内部调 `changeStatus(DocumentStatus.APPROVED, operator)`。**不使用 EXECUTING/COMPLETED**（凭证过账是原子记账动作）。APPROVED→REVERSED 承载"过账后只可冲销"。

`VoucherLine`（值对象）：id/lineNo/accountCode/debit/credit/summary。`create(lineNo, accountCode, debit, credit, summary)` 工厂强制**行级不变式**：debit、credit 均 ≥0、2 位小数（复用 `CostingStrategy.AMOUNT_SCALE`/`ROUNDING`，若不存在则 scale=2 HALF_UP）；**恰好一方>0、另一方=0**（违反抛 IllegalArgumentException）。

`Voucher.create(docNo, period, voucherDate, word, summary, sourceDocType, sourceDocNo, createdBy, lines)` 强制**凭证级不变式**（验收①）：①≥2 行；②行号唯一；③`Σdebit == Σcredit`（BigDecimal compareTo==0）；④总额>0；违反抛 `VoucherNotBalancedException extends IllegalArgumentException`（带 Σ借/Σ贷）。`total_amount=Σdebit`。`restore(...)` 工厂不重跑校验（历史已合法）。

### 领域服务
**AccountService**（端口 AccountRepository）：`create(code,name,type,balanceDir,parentCode,isLeaf,operator)` `@Audited(action="account.create",targetType="account")`（code 唯一、parent 存在且非末级、level 由 parent 推算）；`disable/enable(code,operator)` `@Audited`；`get(code)`→AccountNotFoundException；`listAll()`/`listLeaf()`。

**AccountingPeriodService**（端口 AccountingPeriodRepository）：`open(period,operator)` `@Audited`（已存在拒绝）；`close(period,operator)` `@Audited`（T01 只改状态，结转留 T05）；`reopen(period,operator)` `@Audited`；`get(period)`→AccountingPeriodNotFoundException；`isOpen(period)`。

**VoucherService**（写入口；注入 VoucherRepository、AccountService、AccountingPeriodService、DomainEventPublisher）：
- `create(docNo, period, voucherDate, summary, List<VoucherLineInput> lines, operator)` `@Audited(action="voucher.create",targetType="voucher")`：校验 period 账期**存在**（不要求 OPEN，草稿可建）、voucherDate 落在 period 内、逐行 accountCode 存在且 `isLeaf` 且 `enabled`；构造 `Voucher.create`（不平在此抛）；save。
- `post(docNo, operator)` `@Audited(action="voucher.post",targetType="voucher")`：取凭证；**校验 period 账期 OPEN**，否则抛 `PeriodClosedException`（验收②）；`voucher.post(operator)`；save。
- `reverse(docNo, operator)`：T01 抛 `UnsupportedOperationException`（T07 实现，照 PurchaseInvoiceService.reverse 先例）。
- `get(docNo)`→VoucherNotFoundException；`search(VoucherQuery)`→PageResult。
- 派生只读：`trialBalance(period)`→`List<AccountBalance>`（按 account_code 聚合该期**已过账(APPROVED)**凭证行 Σdebit/Σcredit）；`accountBalance(accountCode, period)`。

`VoucherLineInput(String accountCode, BigDecimal debit, BigDecimal credit, String summary)`；`VoucherQuery(String period, String status, int page, int size)`；`AccountBalance(String accountCode, BigDecimal totalDebit, BigDecimal totalCredit, ...)`。

异常：AccountNotFoundException/AccountingPeriodNotFoundException/VoucherNotFoundException（→404）、VoucherNotBalancedException extends IllegalArgumentException（→400）、PeriodClosedException extends IllegalStateException（→409）。

### 不变式与强制位置
| 不变式 | 位置 |
|---|---|
| 行恰好借或贷一方>0、非负、2 位 | VoucherLine.create |
| 凭证 Σ借==Σ贷 且 总额>0 且 ≥2 行 | Voucher.create |
| 行科目存在/末级/启用 | VoucherService.create |
| 凭证日期落在账期内 | VoucherService.create |
| 过账前账期 OPEN | VoucherService.post |
| 过账后只可冲销不可改 | DocumentStatus 流转表 |
| 凭证无物理删除 | BusinessDocument 继承（无删除方法） |
| 预置科目不可停用/改类别 | Account.disable（is_preset 守门） |
| 账期不可重复关账 | AccountingPeriod.close |

## 8. 风险与决策
1. 状态机映射：DRAFT/APPROVED(过账)/REVERSED/CANCELLED，过账=DRAFT→APPROVED 一步，勿用 COMPLETED。
2. 平衡派生不维护：T01 试算/余额从已过账凭证行 SUM 派生；维护型 account_period_balance 留 T05 关账冻结期末用。
3. 预置走 V19 INSERT（参考数据）。
4. 与既有 accounts_payable/accounts_receivable 台账 T01 不联动（各自独立，联动留 T02；source_doc_no/type 列已预留 + findBySourceDocNo 幂等钩子）。
5. 凭证号 VCH-yyyyMM-序号（中文"记"不兼容 DocumentNumberRule 的 [A-Z] 前缀），word 列存"记"供打印。
6. 账期键 CHAR(6) yyyyMM。
7. 关账守卫在 VoucherService.post（服务层可访问账期仓储）。
8. 全程 BigDecimal/DECIMAL(18,2)、tenant_id=0、UTC。
9. 审计：3 服务写方法 @Audited，聚合实现 AuditTarget，operator 由 app CurrentUser.operator() 传入。
