# M7-T07 响应式 / 平板适配测试与验收记录

## 当前状态

T07 已完成实现（2026-10-21）。从已合入 `main` 的 M7-T05（antd 组件库，PR #63）与 M7-T06（报表前端，PR #62）派生。目标场景：小企业老板用手机（约 375–430）或平板（约 768–1024）看报表与客户/供应商/仓库档案，不必完整重做桌面单据工作台。未改 `web-dist/`，未改 `server/`。

## 布局决策（不新开 ADR）

沿用 ADR-004：深蓝侧栏、登录、聊天继续手写 CSS，业务页经 `web/src/ui` 用 Ant Design React 5。本刀不引入 `Layout`/`Menu`，也不引入第二套设计系统。

| 宽度 | 壳 | 聊天 | 报表 / 已迁 antd 档案 |
| --- | --- | --- | --- |
| ≥1024 | 固定 200px 侧栏 | 会话轨 220px 并排 | 筛选行内，表格完整列 |
| 768–1023（平板） | 顶栏「菜单」+ 自定义抽屉侧栏（遮罩 / Esc 关闭） | 会话轨仍并排 | 工作台页签横向滚动；表格 `scroll.x = max-content` |
| ≤767（手机，含 375–430） | 同上抽屉侧栏 | 顶区「会话」+ 抽屉化会话轨 | 筛选改为纵向铺满；档案次要列 `responsive: ['md']` 隐藏，金额列保留并可横滚 |

断点常量：`COMPACT_SHELL_MEDIA = (max-width: 1023px)`，`COMPACT_CHAT_MEDIA = (max-width: 767px)`。Drawer / Modal 宽度用 `min(设计宽, 100vw)`，避免 420/520 撑破 375。

## 改了哪些壳 / 页

- **壳**：`App.tsx` 顶栏菜单按钮 + 遮罩；`Sidebar` 仍自定义 CSS，窄屏 `position: fixed` 滑入。
- **聊天**：`ChatPanel` / `SessionRail` 窄屏抽屉化；登录页 `LoginPage.css` 补 430 断点。
- **报表**：`WorkbenchTable` 统一横向滚动；`QueryTable` 列 ellipsis；图表容器 `overflow-x: auto`；工作台页签可横滑。
- **档案**：客户 / 供应商 / 仓库筛选控件改为 `max-width: 100%`；联系人/电话/第三列在 `< md` 隐藏，名称与状态保留。
- **封装**：`AppDrawer` / `AppModal` 限宽在视口内。

未一次重写采购/销售/生产单据工作台。页签与页面 padding 的全局窄屏规则会让它们勉强可看，但不作为本刀验收页。

## 红线

- 金额 / 数量仍字符串（`formatAmountText`，禁止 float）。
- 权限 fail-closed（档案写权限与报表页签逻辑不改）。
- 错误展示后端 `{error}` 原文。
- 禁止改 `web-dist/`。

## 本刀不做

- 全站单据工作台像素级重做
- 新 ADR / 新组件库 / 改 `server/`
- 把侧栏迁到 antd `Menu`

## 自测宽度

在浏览器开发者工具切：

1. **390 × 844**（常见手机）：登录可提交；打开菜单进「报表」筛选可点、表可横滑阅读；客户档案列表可搜、点行出抽屉。
2. **768 × 1024**（平板竖屏）：菜单抽屉可用；报表与档案列表可滚动。
3. **1024 × 768** 及以上：侧栏固定，桌面布局不变。

## 自动化覆盖

- 前端 `web/test/responsive-layout.test.js`：断点常量、壳抽屉源码守门（Hooks 在登录早退之前）、表格横滚与列优先级、筛选/Drawer/Modal 限宽、聊天/登录不引用 antd、不碰 `web-dist/`。
- 既有 `ui-shell.test.js` 仍断言聊天/登录/侧栏不迁 antd。
