## 当前状态

T04 已完成实现。在 M8-T03（`52a158b`）之上增加 Actuator/Prometheus 本机刮取、LLM token 日报（读 `agent_invocation`）、宿主机 `monitor.sh`（健康 / 磁盘 / 备份新鲜度 / ERROR 日志 / 可选 webhook）。**未改 `web-dist/`**，未改 Flyway 业务迁移与领域状态机。

## 验收范围

- 应用：`GET /actuator/prometheus` 匿名（仅 127.0.0.1:8081）、`env`/`heapdump` 仍 401；`GET /api/ops/http-summary` 与 `GET /api/ops/llm-daily` 仅 ADMIN/BOSS
- LLM 日报：有单价才出 `estimatedCost` 字符串；未配单价金额为 null，不编造 0 元账单
- `./deploy/monitor.sh`：磁盘、`deploy/backups/**/latest.*` 年龄、`/api/health`、可选 Prometheus 与 ERROR 日志；`--check` 含过期备份自测
- 文档：本文件 + `docs/部署-监控告警.md`，并从一键安装 / 备份 / 安全基线 / README / 路线图链入
- CI「部署资产」：`--check` → 一键安装冒烟 → `restore-smoke.sh` → `monitor.sh`（HTTPS 自签时 health 仍 `curl -k`）
