# SJHERP 演示种子试点（M8-T07）

给运维 / QA 在**预发或本地**装一套虚构小企业账，把「部署 → 完整会计期间 → 缺口通道」干跑通。**不是**真实客户进场。

一键安装见 [部署-一键安装.md](./部署-一键安装.md)；勾选清单见 [测试-M8-T07种子用户试点.md](./测试-M8-T07种子用户试点.md)。

## 1. 不要在生产打开启动开关

| 变量 | 默认 | 说明 |
|---|---|---|
| `SJHERP_DEMO_SEED` | `false` | `true` 时应用启动经领域/应用服务装种子。生产保持 false |
| `SJHERP_DEMO_SEED_PACK` | `sunshine` | `sunshine` 或 `qinghe` |

compose 已把上述变量传进 app 容器。预发建议仍用脚本走 REST，便于看返回的单据号。

## 2. 装种子

```bash
chmod +x deploy/seed-pilot.sh
./deploy/seed-pilot.sh --check     # 不需要 Docker
./deploy/seed-pilot.sh             # 登录 admin，装 sunshine
./deploy/seed-pilot.sh --pack qinghe
```

权限：`pilot:seed`（ADMIN/BOSS）。脚本用 `deploy/.env` 的 `SJHERP_ADMIN_PASSWORD` 登录，不打印 token。

等价 REST：

```bash
POST /api/pilot/demo-seed
{"pack":"sunshine"}
GET  /api/pilot/demo-seed/packs
```

## 3. 单租户如何「换一家」

v1.0 一套库只有一个租户。两套种子包**不能**同时记账。

- 空库直接装 sunshine 或 qinghe
- 已装 sunshine 再装 qinghe → 409，提示恢复空库
- 切换：对**非生产**卷做备份后恢复到空库，或新环境重装，再装另一包

## 4. 种子里有什么

经济口径对齐月末关账验收：采购 100@12.50，销售 60@25.00，毛利 750.00。账期 = 当前 UTC 月。

| pack | 主体 | 仓 / 商品 / 往来 |
|---|---|---|
| sunshine | 演示阳光文具 | 演示阳光仓、演示中性笔、演示草稿纸（期初）、演示晨光供应商、演示文具零售客户、演示工行基本户 |
| qinghe | 演示青禾食品 | 演示青禾仓、演示挂面、演示面粉（期初）、演示粮油供应商、演示社区超市客户、演示农行基本户 |

单据走状态机，备注带 `SJHERP-DEMO-SEED:{pack}`。**不关账**。关账预检与关账仍走 `/api/gl/periods/{period}/close-precheck` 与 close。

## 5. 失败常见原因

| 现象 | 处理 |
|---|---|
| 409 已装另一包 | 恢复空库或继续用已装的包 |
| 409 账期已关 | 换新库或按财务流程重开后再装 |
| 403 | 当前用户没有 `pilot:seed` |
| 启动就灌演示账 | 生产把 `SJHERP_DEMO_SEED` 保持 false |
