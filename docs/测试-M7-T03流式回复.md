# M7-T03 流式回复测试与验收记录

## 当前状态

T03 已完成实现与本地聚焦验收（2026-10-21），还技术债 D-4。未改 `web-dist/`。未实现 M7-T04 多会话管理、M7-T05 组件库、M7-T06 报表前端。

## 验收范围

- 选项返回协议演进为 **v0.2**：完整 `AgentReply` 字段与 v0.1 兼容；新增 SSE 消息流式分片（`status` / `delta` / `complete` / `error`）。三处契约同步：`docs/选项返回协议.md`、`server/sjherp-agent/.../reply/`、`web/src/types/agent.ts`。
- 非流式客户端：`POST /api/chat/sessions/{id}/messages` + `Accept: application/json` 仍返回完整 AgentReply JSON。
- 流式客户端：同一路径 + `Accept: text/event-stream`。`delta` 只含正文增量，`complete.reply` 含 options/form/requiresConfirmation，拼接 delta 等于最终 `text`。
- LLM 终轮走 OpenAI 兼容 `stream: true`；工具轮不向用户转发碎片。HIGH 工具仍框架拦截，确认卡片只出现在 `complete`。
- 前端聊天区消费 SSE，正文逐步渲染（打字机光标），结束后再渲染选项/表单。HTTP 错误与断线有可读提示，错误文案优先后端原文。权限 fail-closed（401 清登录态与聊天会话）。金额/数量仍字符串。
- **禁止改 `web-dist/`**（预发静态由运维另发）。

## 自动化覆盖

- `AgentReplyTextExtractorTest`：分片抽出 `text`、转义/unicode、markdown 围栏、非 JSON 不吐增量。
- `AgentReplyJsonCodecStreamTest`：v0.1 完整回复仍可解析；流式分片往返并可还原 HITL 确认卡片。
- `OpenAiCompatibleLlmClientTest`：请求体 `stream=true`；固定 SSE 样本边推边拼 content。
- `AgentLoopTest`：无工具终轮转发 delta；工具轮 + HIGH 拦截零 delta；`JSON_SEPARATE_FINAL_CALL` 只流式终轮 JSON。
- `ChatServiceStreamingTest` / `ChatServiceToolConfirmationTest`：占位 Agent 流式还原并落库；流式 HITL 确认卡片与确认后执行。
- 前端 `chat-stream.test.js` / `agent-protocol.test.js`：SSE 解析、还原、options 仅 complete、断线文案、三处版本一致。
