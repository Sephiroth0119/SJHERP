# M8-T01 一键部署测试与验收记录

## 当前状态

T01 已完成实现（2026-10-21），分支 `cursor/m8-t01-one-click-deploy-88a6`。生产向 docker compose 覆盖 **nginx / app / MySQL 8.4 / Qdrant**；安装脚本、升级脚本（Flyway 随 app 启动自动迁移）、env 模板与部署文档已落地。**未改 `web-dist/`**，未改业务领域逻辑。

## 验收范围

- 生产 `deploy/docker-compose.yml`：app（Spring Boot 可执行 jar）+ mysql + qdrant + nginx（从 `web/` 构建静态并反代 `/api`，含 SSE 长超时）。
- 密钥走 `deploy/.env.example`（示例值）与 git 忽略的 `deploy/.env`；安装脚本在缺失时生成随机密钥。
- `./deploy/install.sh`：Ubuntu 上可装 Docker → 构建启动 → 等健康 → 打印 URL 与 admin 提示。
- `./deploy/upgrade.sh`：可选 git pull、升级前 mysqldump、重建启动；回滚边界写入 `docs/部署-一键安装.md`。
- 冒烟：登录页含 SJHERP；`GET /api/health` 为 UP；可选 admin 登录。
- 禁止改 `web-dist/`；不引入未登记重量级框架。

## 本刀不做

- HTTPS / 密码策略加固 / API 限流（M8-T03）
- MySQL 定时备份与 Qdrant 快照演练（M8-T02；升级脚本仅有一次性 dump）
- Ollama 与大记忆默认开启（记忆默认关）
- 改业务状态机、领域服务或 Flyway 业务脚本

## 自动化覆盖

- `./deploy/install.sh --check`、`./deploy/upgrade.sh --check`：bash 语法 + 必填环境变量 + `docker compose config`
- CI job「部署资产」：上述 dry-run，并 `docker compose build` 构建 app/nginx 镜像；有 Docker 的 runner 再 `up` 做健康/登录冒烟
- 后端既有测试不因 Hikari 等待与 `SJHERP_CONSISTENCY_ENABLED` 占位而改变默认关巡检
