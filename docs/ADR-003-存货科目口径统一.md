# ADR-003：存货科目口径统一（采购入库 vs 生产领料归集）

- **状态**：草案（Proposed，待会计/用户裁定）
- **日期**：2026-06-28
- **来源**：M5-T08 交叉校验发现 P2-B（设计真源 docs/M5拆解-M5交叉校验.md §6.3）
- **关联红线**：CLAUDE.md 不可妥协原则 2（财务数据专业性：科目分类正确、账证一致）
- **技术债编号**：R-T08-2

## 1. 背景与问题（Context）

M5-T08 生产链交叉校验发现：**原材料采购入库与生产领料归集使用了不一致的存货科目口径**。

- **M3 采购入库**（`AutoVoucherService`，采购入库自动凭证）：子件采购入库记 **借 1405 库存商品 / 贷 220201 暂估应付**。即外购物料统一进 **1405**。
  - 证据：`server/sjherp-app/src/main/java/com/sjherp/app/gl/AutoVoucherService.java`（采购入库分录 1405）。
- **M5-T06 生产料归集**（`ProductionCostVoucherService`，成本结转料归集凭证）：领料归集记 **借 5001 生产成本 / 贷 1403 原材料**。即生产消耗物料从 **1403** 贷出。
  - 证据：`server/sjherp-app/src/main/java/com/sjherp/app/production/ProductionCostVoucherService.java`（`ACC_RAW_MATERIAL="1403"`，料归集 借5001/贷1403）。

### 后果
1. **1403 原材料从未被借记**（采购入库进的是 1405），生产领料却从 1403 贷出 → **1403 出现贷方（负资产）余额**。
2. **1405 库存商品虚高**——既含原材料采购，又含产成品完工入库，科目语义混淆。
3. **资产负债表「原材料 / 库存商品」分类失真**。
4. **缓解事实**：存货**总额**（1403 + 1405）经正负偏移仍与库存子账总额 tie-out（料从 1405 隐性留存、1403 负偏移相抵），故「存货总额」对账成立，仅「科目级分类」错。当前测试夹具（`ProductionCostSettlementFlowIntegrationTest`）直接 `inventoryService.inbound` 预置子件、未走采购自动凭证，掩盖了该错配，故此前未暴露。

## 2. 决策（Decision）

> **本 ADR 为草案，最终科目口径由会计/用户裁定。** M5-T08 本批**不改科目口径**（修复触及 M3 采购凭证模板，范围超出 T08「交叉校验」本身），仅登记本 ADR + 技术债 R-T08-2 排后续任务修复。

候选方案（待裁定择一）：

### 方案 A：采购物料入 1403 原材料（推荐方向，制造业惯例）
- 制造业子件采购入库改记 **借 1403 原材料**；生产领料归集维持 **贷 1403**；产成品完工入库进 **1405 库存商品**。
- 科目语义清晰：1403=未投产原料、1405=可售产成品。
- 代价：需改 M3 `AutoVoucherService` 采购入库分录 1405→1403；需甄别「采购的是原料还是转售商品」（纯贸易转售商品仍应进 1405）——可能需要商品档案上的「存货类别」标识。

### 方案 B：生产领料归集改贷 1405
- 维持采购入库 1405，生产领料归集从 1405 贷出（借5001/贷1405）。
- 代价：1405 同时承载原料与产成品，科目语义仍混（不区分原料/产成品），但避免 1403 负余额；与制造业惯例不符，不推荐。

### 方案 C：引入「存货类别」维度，按商品档案存货属性路由科目
- 商品档案增「存货科目映射」（原材料→1403、库存商品→1405、半成品→1404 等），采购入库与生产领料/完工入库均按商品存货类别路由对应科目。
- 最彻底、最规范，但工作量最大（档案改造 + 凭证模板按类别路由 + 迁移历史数据）。

## 3. 影响（Consequences）

- **规则17（产成品账证 1405 GL↔库存勾稽）延后**：在科目口径统一前，1403/1405 错配会使账证勾稽规则持续误报，故 M5-T08 不固化规则17，随本 ADR 裁定落地后再补（设计真源 §6.2 / §7 R-T08-3）。
- 修复方案落地时须：①迁移/冲销历史错配凭证（财务只可冲销不可物改，红线 2）②补采购→生产组合的端到端集成测试（覆盖本次夹具盲区）③更新财务报表科目映射。
- 在裁定落地前，**存货总额对账仍成立**，不影响存货总值正确性，仅科目级分类失真——故定级为结构性隐患（非阻塞活跃缺陷），可排后续任务从容处理。
