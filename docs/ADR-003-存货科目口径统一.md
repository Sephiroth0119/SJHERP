# ADR-003：存货分类与会计科目统一

- 状态：已采纳
- 日期：2026-07-12
- 来源：M5-T08 交叉校验发现的 1403/1405 科目错配，以及成本结算未扣退料问题

## 背景

此前采购入库固定借记 1405，而生产成本结算固定贷记 1403。原材料从未借记却被生产领料贷出，会形成 1403 负余额；同时成本结算仅累计领料，未扣除已过账退料，导致材料成本被高估。

## 决策

商品档案增加不可任意配置的 `InventoryCategory`，以固定会计政策路由科目：

| 存货分类 | 会计科目 |
| --- | --- |
| `RAW_MATERIAL` | 1403 原材料 |
| `SEMI_FINISHED` | 1405 库存商品 |
| `FINISHED_GOOD` | 1405 库存商品 |
| `MERCHANDISE` | 1405 库存商品 |

具体规则如下：

1. 新建商品必须指定存货分类；历史商品迁移为 `MERCHANDISE`。
2. 商品一旦存在任何库存流水，禁止修改存货分类，避免同一历史库存被跨科目重新解释。
3. 采购入库自动凭证按入库行商品分类汇总借记 1403/1405；销售出库按 COGS 行商品分类汇总贷记 1403/1405。
4. 成本结算按工单计算净领料：已过账领料减已过账退料。结算行持久化 `raw_material_cost`、`goods_material_cost` 和两者之和 `material_cost`，三者必须一致。
5. 生产成本凭证将原材料净额记为“借 5001 / 贷 1403”，商品类材料净额记为“借 5001 / 贷 1405”；完工结转继续“借 1405 / 贷 5001”。
6. 一致性规则 17 按工单核对 `PRODUCTION_IN + COST_ADJUST` 的生产存货成本与生产成本结算凭证 1405 净借方。凭证红冲计入净额；差异超过 0.01 元为 ERROR，阻断月末关账。

## 历史数据与审计边界

本次迁移仅新增分类和成本拆分列，既有商品默认 `MERCHANDISE`，既有成本结算行将 `goods_material_cost` 回填为原 `material_cost`。不修改库存流水、库存余额或历史凭证。

如需调整历史分类或科目，只能在未来通过受控的会计调整/冲销单据完成；不得通过迁移或脚本物理修改已过账财务记录。

## 后果

- 原材料采购、领料和成本归集使用一致的 1403 口径。
- 商品类材料和产成品继续落在 1405，但通过商品分类保留业务解释。
- 生产成本结算的材料成本以“净领料”为单一口径，退料不会再虚增工单成本。
- 新规则会将生产存货与总账的偏差提升为可审计的关账阻塞项。
