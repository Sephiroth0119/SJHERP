# 操作手册 — Agent 聊天

Agent 助手是主入口：用对话完成查询和下单，需要你拍板时弹出 **选项卡片**，而不是让你打一篇说明。

## 怎么开始

1. 左侧 **Agent 助手**。登录用户可以新建、切换、重命名自己的会话，也可以归档（关闭，不是删除）。
2. 直接说要做的事，例如「给华东金属下一张螺丝采购单」。
3. 回复可能带：
   - 可点的选项卡片（确认 / 改数量 / 取消）
   - 单据卡片：点进去跳到对应工作台（没权限则打不开、不露数据）
   - 流式打字的正文

## 确认卡片（一定要点）

涉及资金、审核、过账、关账的操作，Agent **必须**先给你确认卡片，你点了才执行。这是框架拦截，模型不能跳过。

不要在对话里要求「直接过账别问我」。系统不会照做。

## 权限

Agent 能调用的工具和菜单是同一套权限。仓管不能通过聊天创建客户；会计不能通过聊天无权限过库存。被拒时请看返回原因，或换有权限的人登录。

## 系统做不到的事

如果当前能力真的没有（例如你要的特殊报表还不存在），Agent 应走 **流程缺口**：记场景、期望和缺什么，而不是绕过领域模型直接改数。

缺口由管理员审核后才进入开发。这是为了保住数据模型，不是怠工。

## 数据出境

若公司接了第三方大模型，聊天页会提示业务内容可能离开本机。可选脱敏或仅本地，见部署文档里的安全基线。不要把完整银行账号、身份证往对话框里粘。

## 和传统菜单的关系

同一张采购单，用聊天创建和在采购工作台创建，走的是同一套领域服务。喜欢列表核对、批量改行，用菜单；喜欢口述，用 Agent。不要两套各记各的账。
