# M7-T02c 商品 / 类目 / 单位工作台测试与验收记录

## 验收范围

库存模块保留仓库档案入口，新增商品档案二级入口。覆盖商品查询筛选、分页、详情、新建、编辑、启停，以及类目/单位选择和现有 POST/PUT 维护契约。

## 关键边界

- 商品查询必须带 `page`、`size`，有值时精确传 `keyword`、`status`。
- 商品 POST/PUT 请求体仅允许 `code`、`name`、`spec`、`categoryId`、`inventoryCategory`、`baseUnitId`、`barcode`、`remark`、`unitConversions`。
- `unitConversions[].rate` 保持字符串；不得使用 JS float 运算，并拒绝零值、基本单位和重复换算单位。
- 商品状态动作使用真实 `POST /{id}/enable` 或 `/disable`。
- 类目/单位不调用、不展示 DELETE；维护只使用既有 GET、POST、PUT。
- 无 `catalog:create_product` 时不显示新建；无 `catalog:write` 时不显示编辑/启停/维护操作，后端仍是最终授权边界。
