## 1. domain 约当量纯函数 `EquivalentUnitsTest`（7 例）
`全部完工_无在产_工费全归完工`、`完工与在产50pct_约当量与分摊正确_加总等于总额`、`在产100pct_视同完工约当量`、`在产0pct_工费全归完工`、`工费为0_完工在产均0_不除零`、`无任何产出_总约当0_不除零_全归完工`、`除不尽_尾差并入完工_加总仍等于总额`。
> 锁死：单位工费=工费/(完工量+在产约当量)、在产约当量=wipQty×pct/100、**完工分摊+在产分摊≡工费总额无丢分**（尾差并入完工 R-T06-5）、除零防护。

## 2. domain 服务 `ProductionCostSettlementServiceTest`（Fake 全套，~21 例）
- **工费归集**：`create_工费归集_工序无rate用默认费率_费按制造费用率`、`create_工序有costRate_优先用工序费率`、`create_未启用routing也用默认费率_不影响`。
- **完工结转 + 增量防重复（核心）**：`post_完工结转_COST_ADJUST金额为完工工费增量_幂等键正确`、`post_多次结转_增量防重复入账`（跨结转单 Σ守恒）、`post_完工工费增量为0_跳过COST_ADJUST_不报错`、`post_料工费全0_跳过COST_ADJUST`。
- **约当/WIP**：`create_在产50pct_工费部分留WIP`、`create_完工程度越界_拒绝`、`create_在产数量为负_拒绝`。
- **建单校验/状态机**：`create_工单不存在_抛WorkOrderNotFound`、`create_工单状态非EXECUTING或COMPLETED_拒绝`、`create_空行_拒绝`、`approve_DRAFT到APPROVED`、`cancel_仅DRAFT可作废`、`get_不存在_抛NotFound`。

## 4. app 端到端 `ProductionCostSettlementFlowIntegrationTest`（@Tag integration-db，验收核心）
`月末成本结转_产成品料工费_GL平衡_5001留WIP_一致性0ERROR_幂等_关账衔接`：建工单→开工→领料过账→报工过账(T05 料入产成品)→月末成本结转(T06)，断言：① 产成品库存金额=料(T05)+完工工费(T06)/数量不变；② GL 5001/5101/2211/1403/1405 借方 + Σ借=Σ贷；③ 5001 借方余额=期末 WIP（在产工费）；④ ConsistencyCheckService 0 ERROR；⑤ 幂等（重 post 不重复入账）；⑥ 关账 PeriodCloseService.close 成功、5001 留 WIP 余额、损益正常。
> 集成测遵循 T04/T05 CI 教训：TestConfig 提供 `@Bean JdbcStockChecker`、查余额用 `cost_amount`/数量 `quantity`、流水表 `inventory_transaction`、凭证表 `voucher`（总额列 total_amount）。

## 5. app 权限 `ProductionCostSettlementApiPermissionTest`（17 例，主控补齐评审 9.1 缺口）
- **有权（成本是会计动作 D8）**：ADMIN/BOSS/ACCOUNTANT → 建单 201 / 查询 200 / 审核·过账·作废 200。
