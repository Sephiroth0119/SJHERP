# 系统大记忆业务说明

## 1. 解决什么问题

企业里的很多关键知识并不在单据字段里，而散落在老板、财务和业务人员的口头约定中，例如“什么算大客户”“采购准时率按哪个日期计算”“某类异常以后应当怎么处理”。如果这些知识只存在聊天记录或个人经验里，换人、换会话或系统升级后就容易丢失，也无法稳定复用。

系统大记忆把经过确认的业务知识保存为可追溯、可治理的正式记录。首批支持四类：

- `GAP_SOLUTION`：流程缺口已经确认的解决方案。
- `BUSINESS_TERM`：企业自己的业务术语和定义。
- `METRIC_DEFINITION`：指标名称、统计范围和计算口径。
- `OPERATION_PREFERENCE`：不破坏业务规则前提下的操作偏好。

大记忆不是业务单据，也不能替代领域规则。它不能绕过库存、财务、生产等领域服务修改业务数据。

## 2. 三个组成部分

| 组成 | 职责 | 是否可重建 |
|---|---|---|
| MySQL `memory_entry` | 保存完整原文、来源、版本、有效期、治理状态、索引状态和审计信息，是唯一真源 | 不适用，必须备份保护 |
| 本地 Ollama | 使用 `qwen3-embedding:0.6b` 把文本转换为 1024 维向量 | 可以从 MySQL 原文重新计算 |
| Qdrant | 保存向量及最小定位元数据，用于后续语义检索 | 可以从 MySQL 全量重建 |

Qdrant 不保存标题、原文、用户原话或业务正文。Ollama 只在本机运行，本批没有外部 Embedding 回退路径。

## 3. 写入与索引状态

创建记忆时，系统先在一个 MySQL 事务中保存真源。保存成功即代表记忆没有丢失；随后才生成向量并写入 Qdrant。

- `PENDING`：真源已保存，正在等待首次索引或人工重建；此时不能声称已经可被语义召回。
- `INDEXED`：当前活动版本已按指定模型和维度写入 Qdrant。
- `FAILED`：真源仍然安全，但本地 Ollama、Qdrant或向量规格校验失败。系统会按退避时间自动重试，管理员也可以手工重试。

索引错误只保存脱敏摘要，不记录本地 URL、响应正文、记忆原文或密钥。达到自动重试上限后停止高频请求，等待管理员重试或全量重建。

## 4. 版本与治理规则

记忆原文不可原地覆盖：

1. 更新活动记忆时，旧版本进入 `SUPERSEDED`。
2. 新记录沿用同一个 `memoryKey`，版本号加一，并保留 `previousId` 版本链。
3. 新版本以 `ACTIVE + PENDING` 进入索引流程。

失效操作把活动版本标记为 `EXPIRED`，不物理删除 MySQL 真源；对应 Qdrant point 属于可重建派生数据，可以删除。即使派生删除暂时失败，后续召回也必须回查 MySQL，只允许返回有效期内的 `ACTIVE` 版本。

`CONFLICT` 为后续记忆冲突治理预留状态，本批不自动裁决冲突。任何版本都保留来源类型、来源编号、创建人、更新时间和统一审计日志。

## 5. 管理能力与权限

本批提供 `/api/memories` 管理接口：创建、单条查询、分页查询、版本替换、逻辑失效、手工重试索引和全量重建。全部接口要求 `memory:manage`，仅 `ADMIN` 与 `BOSS` 持有。

创建、替代、失效、手工重试和全量重建都有审计记录。审计摘要只记录编号、记忆键、版本、类型和状态，不复制原文。

## 6. 本地运行

1. 启动 MySQL 与 Qdrant：`docker compose -f deploy/docker-compose.dev.yml up -d`。
2. 安装 Ollama，并执行 `ollama pull qwen3-embedding:0.6b`。
3. 设置 `SJHERP_MEMORY_ENABLED=true`。默认地址为 Ollama `http://localhost:11434`、Qdrant `http://localhost:6333`，可分别用 `SJHERP_OLLAMA_URL`、`SJHERP_QDRANT_URL` 覆盖。
4. 用 local profile 启动应用，通过 `/swagger-ui/index.html` 登录授权后调试管理接口。

功能默认关闭。关闭时应用不会创建大记忆客户端，也不会连接 Ollama 或 Qdrant，原有 ERP 与 Agent 功能不受影响。

## 7. 当前边界

M6-T01 交付的是记忆真源、派生索引、版本治理、重试重建和管理入口。聊天前置召回、来源引用和回答注入属于 M6-T03；缺口解决后自动回写属于 M6-T10。本批不会让聊天 Agent 自动使用尚未接入的记忆。
