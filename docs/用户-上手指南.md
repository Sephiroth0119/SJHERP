# SJHERP 上手指南

给第一次打开系统的人看。装好、登录后，按 **建档案 → 期初 → 第一张单** 把账立起来，再按日常工作进菜单或跟 Agent 聊天。

更细的点击步骤见各模块手册；部署安装见 [部署-一键安装.md](./部署-一键安装.md)。

## 1. 登录

浏览器打开安装脚本打印的地址。用户名一般是 `admin`，初始密码在服务器 `deploy/.env` 的 `SJHERP_ADMIN_PASSWORD`。

密码要同时有大写、小写和数字。登录后左侧是业务菜单，默认落在 **Agent 助手**。

## 2. 第一次登录向导

管理员或老板第一次登录，会弹出向导：

1. **建档案**：单位、仓库、商品、供应商；客户可留空稍后补。已有档案可以直接选用，不会替你编造测试数据。
2. **期初**：给仓库里已经在的货补数量和单价。没有存货可以跳过。系统走库存台账的期初入口，不是改库存数字。
3. **第一张单**：创建一张 **采购订单草稿**。向导不会自动审核、入库或开票——那些仍要你在采购工作台点。

「稍后再说」会关掉向导。之后可点顶栏 **新手引导**，或打开左侧 **帮助**。

没有建档/期初/下单权限的账号只会看到欢迎说明，不会出现越权提交按钮。

## 3. 日常怎么用

| 你想做的事 | 走哪 |
|---|---|
| 用说话完成下单、查询、审核 | 左侧 **Agent 助手**，高风险操作要点确认卡片 |
| 看列表、改草稿、过账 | 采购 / 销售 / 库存 / 生产 / 财务菜单 |
| 看库存余额、账龄、利润 | **报表**（部分页签按权限隐藏） |
| 再看一遍上手步骤 | **帮助** |

金额和数量在界面里都是字符串，不要自己用计算器换成小数再粘回来乱改精度。

## 5. 几条红线（先记住）

- 已过账、已完成的单据 **不能删除**，记错了走冲销。
- 下采购单、下销售单都 **不动库存**；入库过账才加库存，出库过账才减库存。
- 应付来自采购发票过账，应收来自销售发票过账；收付款单过账才会核销。
- 凭证必须借贷平衡。关账前若一致性检查报 ERROR，先处理再关。
