## 1. domain 单元测试 `ProductionReportServiceTest`（纯内存，Fake 仓储+端口）
- **建单校验**：`create_工单不存在_抛WorkOrderNotFoundException`、`create_工单非EXECUTING状态_抛异常`、`create_productId不匹配_抛异常`、`create_空工时行_抛异常`、`create_成功_状态DRAFT_行正确`。
- **状态流转**：`approve_从DRAFT到APPROVED`；`cancel_仅DRAFT可作废`、`cancel_APPROVED状态_抛异常`。
- **过账核心**：`post_过账后状态COMPLETED_inboundCost回填_工单completedQty累加`（unitCost=料费÷完工量、PRODUCTION_IN 入库一次、inboundCost 回填、工单 completedQty+5）。
- **成本边界（评审 P0/D3 守门）**：
  - `post_零成本领料_D3_拒绝过账`（无领料→增量=0→拒，防零成本稀释移动加权）。
  - `post_多次报工_D5_completedQty累加_料费不重复入账守恒`（JIT 先领 300 报 3→inbound 300，再领 200 报 4→inbound 200；**Σ入库 500 ≡ Σ领料出库 500**；completedQty=7；超额完工 D5 放行）。
  - `post_分批完工无新增领料_增量料费为0_拒绝过账`（mi 一次领 300 被 pr1 全额结转，pr2 无新增领料→增量=0→拒；pr2 停 APPROVED、工单 completedQty 不前进）。
- **查询**：`get_不存在_抛ProductionReportNotFoundException`。
- WorkOrder.recordCompletion 累加+防负 由 WorkOrderTest 覆盖。

## 2. infra 真库集成测试 `JdbcProductionReportRepositoryIntegrationTest`（@Tag integration-db，仅 CI）
- 落库往返：`save新报工单后findByDocNo_头行字段完整落库`、`save多行报工单_行可选字段为null_回读正确`（operationSeqNo/operationName/workCenter/reportedQty 可空）、`过账后inboundCost回填_update后回读值正确`。
- 状态持久化：`approve流转后save_status持久化为APPROVED`、`cancel流转后save_status持久化为CANCELLED`。
- 查询：`findByDocNo_不存在_返回empty`、`search_按workOrderDocNo过滤`、`search_按status过滤`、`search_分页`、`search_无匹配`。
- **D11 回归**：`D11_工单completed_qty更新后持久化正确`（守门 JdbcWorkOrderRepository.update 补 completed_qty 列——T05 必修点，否则回写静默丢失）。

## 3. app 端到端 `ProductionReportFlowIntegrationTest`（@Tag integration-db，仅 CI，3 例）
- `报工过账_完工入库_库存成本正确_工单完工数量更新_一致性0ERROR`：PURCHASE_IN 预置→建工单→release→start→领料过账（产生料费）→报工过账，断言 PRODUCTION_IN 流水、成品库存数量+金额（成本守恒）、工单 completed_qty 回写、报工单 COMPLETED+inboundCost 回填、ConsistencyCheckService 两维度 0 ERROR。
- `无已过账领料成本_报工过账_抛IAE_单据状态不前进`（D3：无料拒过账，DB 确认 pr 仍 APPROVED、0 条 PRODUCTION_IN）。
- `同一工单多次报工_completedQty累计`（**评审 P0 守门**：JIT 两轮领料+报工，断言 completedQty=7、2 条 PRODUCTION_IN、**pr1 inbound_cost=300 / pr2 inbound_cost=200 / 成品 cost_amount=500=Σ领料出库**——锁死料费不重复入账）。
> 集成测试遵循 T04 CI 教训：TestConfig 提供 `@Bean JdbcStockChecker`（CatalogInfraConfig 依赖）、查余额用 `cost_amount` 列、流水表 `inventory_transaction`。

## 4. app 权限 `ProductionReportApiPermissionTest`（REST 全程受控 production:report，22 例）
- 建/审/过账/作废写操作：ADMIN/BOSS→2xx；SALES/WAREHOUSE/PURCHASE/ACCOUNTANT→403（含统一文案）；未登录→401。
- 查询（列表/详情）：ADMIN/BOSS→200；SALES/ACCOUNTANT→403；未登录→401（**查询同权，全程受控**）。
