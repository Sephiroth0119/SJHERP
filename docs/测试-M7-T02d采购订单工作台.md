## 验收范围

- 采购模块保留 T02b 供应商档案，并增加“供应商档案 / 采购订单”二级切换。
- 采购订单仅调用真实分页、详情、创建、审核、关闭端点。
- 供应商与商品使用真实分页搜索和可读编码/名称选择，不要求输入裸 ID。
- 名称补载失败时明确显示带引用 ID 的“名称不可用”，不长期伪装成加载中。
- 创建请求窄化为 `supplierId/orderDate/remark/lines[productId/quantity/unitPrice]`。
- 数量、单价、金额和到货数量均按字符串承载，无 JavaScript 浮点换算。
- 创建、审核、关闭共享同步 in-flight 守卫，快速双击不会重复发送业务写请求。
- 仅 `purchase:order` 持有者可见订单页签与订单动作；后端类级权限仍是最终边界。
- 不提供编辑、删除、作废、冲销、采购入库或采购发票动作。

## 本地验证

- `npm.cmd test`：29 项通过。其中新增 7 项覆盖：
  - `supplierId/status/page/size` 精确查询参数与详情路径；
  - 查询及 mutation 响应为 JSON number 时，数量、单价、金额、已到/未到数量仍统一归一为字符串；
  - 创建时传入多余字段，证明只透传精确窄请求体；
  - 审核与关闭使用精确 URL 和 `POST`；
  - 调用轨迹无 `DELETE`，API 与界面无虚构编辑/删除/作废/冲销动作；
  - 数量正数、单价非负、至少一行和商品不重复边界。
  - 订单页签严格由 `permissions.includes('purchase:order')` fail-closed 控制；
  - 创建与状态流转共享同步 in-flight 守卫，并在 `finally` 释放。
