# M7-T02a 客户档案工作台测试与验收记录

## 范围

本批次仅交付销售入口下的客户档案列表、关键词/状态筛选、分页、详情、新建、编辑、启用/停用。供应商、仓库、商品、采购/销售单据、库存、生产、财务界面属于后续 M7-T02 小批次，不在本批次验收范围。

## 权限与契约

- 查询与详情：沿用后端客户 API 的登录态访问。
- 新建：前端仅在 `partner:create_customer` 存在时显示按钮。
- 编辑、启用/停用：前端仅在 `partner:write` 存在时显示按钮；后端仍是最终授权边界。
- API：`/api/partner/customers`；金额 `creditLimit` 支持 number/string/null wire 值，前端统一以字符串编辑，空值提交为 `null`。
