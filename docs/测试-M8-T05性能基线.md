## 本地证据（`./deploy/perf.sh --full`，Testcontainers MySQL 8.4，本机 16 GB）

| 步骤 | 结果 |
|---|---|
| V38 迁移 | Flyway 应用到 v38 |
| 4096 行合成灌数 | 127–138 ms |
| 8 并发库存入库 | p50=40–55 ms，p95=42–56 ms，errors=0，对账恒等式成立 |
| 1 048 576 行合成灌数 | **17.2 s** |
| 百万行后 50 并发库存入库 | p50=1068 ms，p95=1071 ms，max=1083 ms，errors=0 |
| 百万行后 50 并发采购入库过账 | p50=598 ms，p95=617 ms，max=619 ms，errors=0 |
| 百万行后 8 并发采购入库过账 | p50=25 ms，p95=28 ms（热路径未被百万行拖成全表扫描） |

50 并发 p95 ≈ 1 s 来自同时打满连接/线程，远低于 10 s 宽松上限。全新 SKU 不先建余额行时会 InnoDB 间隙锁死锁（8 并发曾 6–7 条失败）；口径改为串行 OPENING 再建并发，对齐小企业「已有库存再过账」。

索引目录单测 `RequiredLedgerIndexCatalogTest` + `V38InventoryTxnSrcIndexMigrationContractTest`：2/2 通过。`./deploy/perf.sh --check` 通过。
