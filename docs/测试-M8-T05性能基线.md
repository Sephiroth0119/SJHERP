# M8-T05 性能基线测试与验收记录

## 当前状态

T05 已完成实现。在 M8-T04（`679b601`）之上增加热路径索引守门、MySQL 慢查询日志、可跑的单据过账/库存并发压测。**未改 `web-dist/`**。Flyway 仅 V38：`idx_inventory_txn_src`（EXPLAIN 证明来源单号点查否则全表扫描）。

## 验收范围

- `./deploy/perf.sh --check`：Flyway 声明 `deploy/perf/required-indexes.txt` 中的索引；compose 打开 `slow_query_log`
- `./deploy/perf.sh --smoke`：运行中 compose MySQL 只读 `SHOW INDEX` + EXPLAIN（不 INSERT）
- `./deploy/perf.sh --full`：Testcontainers 百万行合成流水 + 50 并发库存入库 + 50 并发采购入库过账；独立容器，不碰生产卷
- CI integration-db：4096 行 + 8 并发冒烟 + EXPLAIN（`DocumentPostingPerfIntegrationTest`）
- 后端 `mvn verify`：`RequiredLedgerIndexCatalogTest`（无 Docker）
- 文档：本文件 + `docs/部署-性能基线.md`，并从一键安装 / 监控 / README / 路线图链入

## 自动化覆盖

- infra：`RequiredLedgerIndexCatalogTest` 断言 V10/V14/V17/V19/V20/V38 含热路径索引，并与 `required-indexes.txt` 对齐
- app：`DocumentPostingPerfIntegrationTest`（`@Tag("integration-db")`）
  - EXPLAIN：余额 FOR UPDATE、最近成本、幂等键、来源单号、台账倒序
  - 8 并发独立 SKU 库存入库，对账恒等式
  - 8 并发独立 SKU 采购入库过账（先串行建单审核，再并发 `post`）
  - `SJHERP_PERF_SCALE=full` 时倍增到 ≥1 048 576 行再跑 50 并发
- `./deploy/install.sh --check` 含 `perf.sh --check`
- CI「部署资产」在 monitor 之后跑 `perf.sh --smoke`

## 本地如何验

```bash
chmod +x deploy/perf.sh
./deploy/install.sh --check
./deploy/upgrade.sh --check
git diff --stat -- web-dist   # 应无输出

# 后端索引目录（无 Docker）：
cd server
mvn -B -ntp test -pl sjherp-infra -Dtest=RequiredLedgerIndexCatalogTest

# 有 Docker 时，integration-db 冒烟：
mvn -B -ntp test -pl sjherp-app -am -Dtest=DocumentPostingPerfIntegrationTest \
  -Dgroups=integration-db -DexcludedGroups=none

# 百万行 / 50 并发（可选，数分钟）：
cd ..
./deploy/perf.sh --full
```

已有生产 compose 时：

```bash
./deploy/perf.sh --smoke
```

聚焦慢查询：compose MySQL `long_query_time=1`；`docker compose … exec mysql tail` 数据卷内 `*slow*.log`。
