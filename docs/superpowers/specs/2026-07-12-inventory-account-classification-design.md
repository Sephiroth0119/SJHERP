# 存货分类与生产成本净额修复设计

**目标：** 统一采购、销售与生产成本结转的存货科目口径，消除 1403/1405 错配与退料未扣减导致的料费高估，并将生产链账证勾稽固化为关账前 ERROR 校验。

**范围：** 收口 M5-T08 登记的 R-T08-2（存货科目错配）、R-T08-3（规则 17）和 R-T08-4（T06 未按退料取净额）。不实现大记忆 M6，不修改或删除已过账财务记录，不新增自由科目映射。

## 1. 背景

当前采购入库自动凭证固定借记 1405 库存商品，而生产成本结转的料归集固定贷记 1403 原材料。对采购后领用的物料，1403 会形成无借方来源的贷方余额，1405 同时承载原料和产成品，造成资产负债表科目分类失真。

同时，`ProductionCostSettlementService` 汇总工单料费时只累计已过账领料 `issuedCost`，没有减去已过账退料 `returnedCost`。这会高估料费，并相应低估结转到产成品的工费增量。

## 2. 决策

### 2.1 固定存货分类，而非自由配置会计科目

商品档案新增不可空的 `InventoryCategory`：

| 类别 | 含义 | 当前固定 GL 科目 |
|---|---|---|
| `RAW_MATERIAL` | 未投产的原材料 | 1403 原材料 |
| `SEMI_FINISHED` | 可作为上层 BOM 子件的自制半成品 | 1405 库存商品 |
| `FINISHED_GOOD` | 可销售的自制产成品 | 1405 库存商品 |
| `MERCHANDISE` | 外购转售商品 | 1405 库存商品 |

科目映射由应用层唯一的 `InventoryAccountPolicy` 固定维护。商品 API、Agent 工具和领域命令只接收枚举，不接收任意 GL 科目编码。这样既满足制造业的 1403/1405 分类，又不让主数据直接绕过会计政策。

`SEMI_FINISHED` 当前暂映射 1405；小企业预置科目表尚未提供独立半成品科目。未来若引入 1404，只修改映射策略和相应迁移，不改变商品分类语义。

### 2.2 类别变更边界

新增商品必须提供类别。V31 迁移将全部存量商品安全默认成 `MERCHANDISE`，保证升级后行为与原系统一致。

类别一旦存在库存流水即不可变更。首次库存过账前可以修正类别；之后的类别改变会导致当前主数据重解释历史业务，因此必须拒绝。此批不对已过账凭证、库存流水或余额做 Flyway 直接更新。

历史错配凭证保持不变。真实历史账的科目重分类留给独立的、可审核的“存货科目重分类单”任务处理；它必须走领域服务和凭证红冲/新增凭证，不能物理修改历史记录。

### 2.3 业务凭证路由

采购入库在生成凭证时按收货行的商品类别聚合金额：

- `RAW_MATERIAL` 金额借记 1403；
- 其余类别金额借记 1405；
- 每张单仍只有一条贷方 220201 暂估应付款，金额等于全部借方合计。

销售出库按出库行的商品类别聚合 COGS：借方仍为 6401 主营业务成本，各类别成本分别贷记 1403 或 1405。

查询商品失败、类别缺失、分类金额总和不等于原单据金额或凭证不平衡时，业务过账与自动凭证必须处于同一事务内并整体回滚。

### 2.4 生产成本结转快照与净额口径

生产成本结转行保留总料费 `materialCost`，并新增两个创建时冻结的分量：

- `rawMaterialCost`：该工单已过账领料中 `RAW_MATERIAL` 的成本，减已过账退料中同类商品的成本；
- `goodsMaterialCost`：其余类别（半成品、产成品、商品）的同口径净成本。

领域不变式：`materialCost = rawMaterialCost + goodsMaterialCost`，三者均以金额精度两位小数保存。退料累计大于相同类别累计领料、商品缺失或类别无法识别时，创建成本结转单直接拒绝。

这两个分量作为成本结转单行的快照持久化，过账时绝不再读取可变的商品档案。前期累计查询也拆分两类料费，保证跨期增量和已冻结快照使用同一口径。

成本结转凭证按本期增量分别出料归集分录：

- 借 5001 / 贷 1403：原材料料费增量；
- 借 5001 / 贷 1405：半成品、产成品和商品料费增量；
- 人工、制造费用、完工结转沿用既有规则；完工结转仍为借 1405 / 贷 5001。

这保留 T05/T06 的守恒边界：T05 只将料成本写入产成品库存，T06 只通过 `COST_ADJUST` 增加工费，不改写已入库料成本。

### 2.5 规则 17：生产产成品账证勾稽

新增 `PRODUCTION_FINISHED_GOODS_GL` ERROR 规则（规则 17）。以工单为维度比较：

`Σ PRODUCTION_IN.totalCost + Σ COST_ADJUST.totalCost`

与

`Σ 该工单生产成本结转凭证借记 1405 的金额`

两者只允许一分舍入容差。差异超过 0.01 时记录 ERROR，`PeriodCloseService` 的既有一致性闸门必须阻止关账。

规则限定生产来源单据和生产成本结转凭证，不纳入当前尚未自动生成凭证的期初、盘点和通用成本调整，因此不会对既有范围外流水误报。

## 3. 组件与职责

| 组件 | 职责 |
|---|---|
| `InventoryCategory` | 领域枚举，定义四种商品存货语义。 |
| `Product` / `ProductService` | 保存、校验并审计商品分类；通过库存流水查询端口阻止已使用商品变类。 |
| `InventoryAccountPolicy` | 应用层唯一类别→1403/1405 的会计映射。 |
| `AutoVoucherService` | 为采购入库、销售出库按商品行类别聚合并出平衡凭证。 |
| `ProductionCostSettlementService` | 按“领料减退料”计算并冻结两类料费；维护加总不变式。 |
| `ProductionCostSettlementLine` / 仓储 | 存储、回读和累计两类料费快照。 |
| `ProductionCostVoucherService` | 用冻结快照及前期累计按账户拆分本期料归集增量。 |
| `ConsistencyCheckDao/Service` | 聚合生产库存流水和生产凭证，执行规则 17，只读报告错误。 |

## 4. 数据与迁移

V31 只做下列安全的数据结构变更：

1. `product.inventory_category VARCHAR(32) NOT NULL DEFAULT 'MERCHANDISE'`；
2. `production_cost_settlement_line.raw_material_cost DECIMAL(19,2) NOT NULL DEFAULT 0.00`；
3. `production_cost_settlement_line.goods_material_cost DECIMAL(19,2) NOT NULL DEFAULT 0.00`；
4. 对已存在成本结转行回填 `goods_material_cost = material_cost`，`raw_material_cost = 0.00`。

迁移不得更新 `voucher`、`voucher_line`、`inventory_transaction` 或 `inventory_balance` 的业务金额与状态。财务历史修正必须使用运行时领域服务。

## 5. API、权限与审计

商品创建、更新和查询响应新增 `inventoryCategory`；沿用既有 `catalog:product` 权限与 `@Audited` 审计。无新权限点。

现有 Agent 商品建档工具的参数和返回体同步增加类别，仍由既有工具权限守卫。成本结转工具不接收料费或科目参数，继续由领域服务计算；规则 17 复用既有一致性检查 REST、计划任务和工具。

## 6. 测试与验收

### 单元测试

- 商品默认/显式分类、未使用商品变类、已有库存流水商品变类被拒；
- 多类别采购入库与销售出库凭证分组、借贷平衡、总额守恒、商品缺失整体失败；
- T06 原料/非原料混合领料、同类退料、退料后净额、超退拒绝、`materialCost` 加总不变式；
- 两期或乱序边界下分账户前期累计与本期增量不重复；
- 规则 17 的相等、一分以内差异、超过一分、缺任一侧记录等边界。

### 集成测试

新增真库“采购原料 → 领料 → 退料 → 报工完工 → 成本结转 → 销售”链路，断言：

1. 原材料采购借 1403，外购商品借 1405；
2. 生产料归集按冻结分类分别贷 1403/1405；
3. 完工结转借 1405，所有生产凭证借贷平衡；
4. `PRODUCTION_IN + COST_ADJUST` 与生产凭证 1405 借方在一分容差内相等；
5. `ConsistencyCheckService.check()` 无 ERROR，正常关账成功；
6. 直接制造一笔账证错配后规则 17 返回 ERROR，关账被拒且账期保持 OPEN；
7. 全反应堆单测和 `integration-db` 回归通过。

## 7. 明确不做

- 不做商品级任意 GL 科目输入；
- 不自动猜测或重写历史商品类别；
- 不自动冲销或修改已过账凭证；
- 不在本批增加独立半成品科目或存货科目重分类单；
- 不改变 M6 大记忆范围。

## 8. 风险与后续

- 历史已错配数据在重分类单交付前仍保留原样，但不会被本批加剧；
- V31 对旧成本结转行按“全部非原材料”回填，只保障历史可回读，不重新解释历史凭证；
- 规则 17 的一分容差仅用于金额舍入，不能掩盖实质账证差异；
- R-T06-8 的“双锚点建单/过账窗口”问题仍独立登记，后续应将 GL 增量改为同一冻结锚点并补乱序真库测试。
