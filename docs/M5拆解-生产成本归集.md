# M5-T06 生产成本归集与结转 拆解与实现方案

> 路线图 §7 M5-T06（L 级，**全项目最难财务点**）。本文是 T06 实现单一设计真源；会计政策真源见 docs/生产成本核算规则.md（ADR）。
> 范围：工单维度归集 料/工/费 → 约当产量法计完工/在产 → 完工工费经库存唯一入口追加产成品成本（CostAdjustCommand）→ 出 GL 凭证 → 月末 WIP=5001 借方余额。
> 验收：端到端 领料→报工→月末成本结转→GL（Σ借=Σ贷）→ 产成品成本=料+工费 → 5001 留 WIP 余额 → ConsistencyCheckService 0 ERROR → 关账衔接成功。

## 0. 范围红线 + 关键事实（已核对代码）
- **做**：ProductionCostSettlement（PC- 月末成本结转单）按工单归集料工费 + 约当产量法分摊 + CostAdjustCommand 追加完工工费到产成品 + ProductionCostVoucherService 出 GL。
- **不做**：Agent 工具（T07）、报废成本单独分摊（R-T06-4）、结转单冲销（R-T06-6）、真实制造费用池（R-T06-1）。
- **关键事实**：①T05 增量料费守恒已稳固，T06 **不动 inboundCost**，只加工费增量。②科目全在 V19（5001/5101/2211/1405/1403），无需新增。③`CostAdjustCommand`（NEUTRAL，调金额不调量，走 InventoryService.adjustCost 唯一入口）已存在=T06 加工费正确机制，无需新 InventoryTxnType。④Routing 工序行有 cost_rate/work_center（V25 已建列）。⑤PeriodCloseService 明确把 COST 类留 M5、关账只断言 PROFIT_LOSS 净额=0、不碰 5001/5101。最新迁移 V29→本批 **V30**。

## 1. 领域模型（com.sjherp.domain.production）
- `ProductionCostSettlement extends BusinessDocument`（PC- 月末成本结转单，header：period CHAR(6)/六态/审计）+ 行集合。轻量单据：DRAFT→APPROVED→EXECUTING→COMPLETED（过账=算约当+COST_ADJUST+出 GL）。
- `ProductionCostSettlementLine`（每工单一行）：workOrderDocNo / materialCost / laborCost / overheadCost / completedQty / completedCost / wipQty / wipCompletionPct / wipCost / alreadyTransferred（前期已结转工费锚点）/ costAdjustIdemKey / voucherDocNo。
- `ProductionCostSettlementService`（@Audited create/approve/post + get/search）：
  - create：按 period 聚合该期所有"有完工或在产"的 EXECUTING/COMPLETED 工单，每工单算 料(Σ领料 issuedCost)/工(Σ报工 hours×routing costRate)/费(Σhours×overheadRate)；按约当产量法分摊完工/在产；录入 wipCompletionPct。
  - post：对每行——CostAdjustCommand 追加完工工费增量(=完工应负担工费−alreadyTransferred)到产成品仓 → ProductionCostVoucherService 出料归集/工费归集/完工结转凭证 → 回填 voucherDocNo。同一 @Transactional。
- 约当量/分摊纯函数（可独立单测）：单位工费=工费/(完工量+在产约当量)；尾差并入完工部分（R-T06-5）。
- 依赖：ProductionCostSettlementRepository + WorkOrderRepository + MaterialIssueRepository + ProductionReportRepository + RoutingRepository + InventoryPostingPort（CostAdjust）+ 成本参数源。

## 2. 成本参数（D1 落地）
- 工费率：Routing 工序 costRate；缺失用默认人工费率。制造费用率：配置参数（元/工时）。
- v1.0 落地：新增 `production_cost_param`(period/default_labor_rate/overhead_rate) 表 + 简单读取，或复用系统参数。**推荐独立小表**便于按期维护 + 审计。

## 3. 迁移 V30__production_cost_settlement.sql（照 V28/V29 风格）
utf8mb4 / DATETIME(6) / DECIMAL 禁 float / tenant_id DEFAULT 0 入唯一键最左。
- `production_cost_settlement`(id/tenant_id/doc_no[uk]/period CHAR(6)/status/审计4)
- `production_cost_settlement_line`(id/tenant_id/settlement_id/line_no/work_order_doc_no/material_cost DECIMAL(18,2)/labor_cost/overhead_cost/completed_qty DECIMAL(18,6)/completed_cost DECIMAL(18,2)/wip_qty DECIMAL(18,6)/wip_completion_pct DECIMAL(5,2)/wip_cost DECIMAL(18,2)/already_transferred DECIMAL(18,2)/cost_adjust_idem_key VARCHAR(200)/voucher_doc_no VARCHAR(64)；uk(tenant_id,settlement_id,line_no))
- `production_cost_param`(id/tenant_id/period CHAR(6)/default_labor_rate DECIMAL(18,6)/overhead_rate DECIMAL(18,6)/审计；uk(tenant_id,period))
- 无需新增科目（V19 全有），无需新 InventoryTxnType（COST_ADJUST 复用）。

## 4. GL 凭证（ProductionCostVoucherService，app/gl 或 app/production）
照 AutoVoucherService 范式（金额≤0 跳过 / findBySourceDocNo 幂等 / ensurePeriodExists / createFromSource+post）。source_doc_type="PRODUCTION_COST_SETTLEMENT"、source_doc_no=PC 单号(+工单后缀避 uk_voucher_source 冲突)。分录见 ADR §5（料归集 借5001/贷1403、工费归集 借5001/贷2211+5101 两段式、完工结转 借1405/贷5001）。

## 5. REST + 权限（类级 @PreAuthorize('production:cost')）
- /api/production/cost-settlements：POST 建单(period) / {docNo}/approve|post / GET 查询·{docNo}（受控）。
- AppService 直标 @Transactional（跨 COST_ADJUST + GL + 单据状态原子，照 PeriodCloseService/ProductionReportAppService）。
- 新权限点 `PRODUCTION_COST("production:cost","生产成本归集与结转")` → Permission 枚举 + RolePermissions（ADMIN/BOSS/ACCOUNTANT）+ RolePermissionsTest 期望集（三处同步红线）+ 权限矩阵.md。
- ProductionExceptionHandler +ProductionCostSettlementNotFoundException→404；账期 CLOSED→PeriodClosedException→409；料工费=0 工单跳过非报错。

## 6. 一致性勾稽（D9）
ConsistencyCheckService 加规则"已完工工单的工费已结转"（completedQty>0 但无对应结转记录 → WARN 非阻塞，避免误卡关账）。库存恒等式规则1/2 因 COST_ADJUST quantity=0 自然不破。

## 7. 测试
- domain 单测（fake 仓储+InventoryPostingPort+Routing/PR/MI）：工费归集 Σ(hours×rate)、工序无 rate 兜底；约当量（完工+在产约当=总约当、单位成本、分摊加总=本期工费无丢分）；完工结转 CostAdjustCommand adjustAmount=完工工费增量+幂等键+多次结转增量防重复；WIP 完工程度 0/50/100%；料费/工费=0 跳过；完工程度越界拒。
- infra @Tag(integration-db)：settlement 头+行往返/分页/voucher_doc_no 回填/COST_ADJUST 流水。
- app @Tag(integration-db) 端到端：建工单→开工→领料过账→报工过账(T05 料入产成品)→月末成本结转(T06)→断言①产成品金额=料(T05)+完工工费(T06)、数量不变②GL 5001/5101/2211/1405/1403 + Σ借=Σ贷③5001 借方余额=期末 WIP④ConsistencyCheckService 0 ERROR⑤幂等(重 post 不重复入账)⑥关账衔接 PeriodCloseService.close 成功、5001 留 WIP。
  集成测注意（T04/T05 CI 教训）：TestConfig 提供 StockChecker bean、查余额用 cost_amount 列、流水表 inventory_transaction。
