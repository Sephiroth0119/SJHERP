# 操作手册 — 库存

库存台账是存货数量和成本的真源。采购入库、销售出库、盘点、调拨、生产领料都走同一套写入口。

菜单：左侧 **库存**。

## 仓库与商品

见 [用户-操作手册-档案.md](./用户-操作手册-档案.md)。期初之前这两个档案必须先有。

## 台账与期初（库存 → 台账）

- 按仓库、商品查余额和流水。数量、成本金额按字符串显示。
- 有 `inventory:adjust` 时可以做：
  - **期初建账（OPENING）**：数量大于 0，单价 ≥ 0。第一次上线补库存用这个。
  - **成本调整**：只调金额不调数量，给核算纠偏用。
- 新手向导的「期初」就是调用这个期初接口。也可以由管理员用 Excel 批量导入，见 [业务-期初导入.md](./业务-期初导入.md)。
- Excel 导入发现该仓该商品已有库存会整批拒绝，避免期初做两次。界面单条期初按普通入库累加，请不要对同一批货重复点。

## 盘点（库存 → 盘点）

权限：`inventory:count`。

1. 新建盘点单，选仓库，把每一行的实盘数量录完才能审核。
2. 过账后：实盘多于账面 → 盘盈入库；少于账面 → 盘亏出库。
3. 已完成的盘点单不能改、不能删。

## 调拨（库存 → 调拨）

权限：`inventory:transfer`。

1. 新建，选调出仓、调入仓（不能相同）和商品数量。
2. 过账时一出一入同时完成，金额守恒。失败则两边都不动。

## 成本口径

系统用 **移动加权**。不要手工改流水里的单价去「调利润」。出库成本由系统在过账时计算。
