# 操作手册 — 销售

销售分三张单：**订单 → 出库 → 发票**，最后用收款单核销应收。

菜单：左侧 **销售**。

## 销售订单（销售 → 销售订单）

1. 新建，选客户，填行：商品、数量、单价。
2. 保存草稿后 **审核**。下单 **不扣库存**。
3. 如果指定了仓库且库存不够，系统会提示，但仍然允许下单（可以先订后进货）。
4. 草稿可作废。

权限：`sales:order`（管理员 / 老板 / 销售）。

## 销售出库（销售 → 销售出库）

1. 选一张**已审核、还没发完**的销售订单，选发货仓。
2. 可以分批发货；超过未发量会被拒绝。
3. 审核后 **过账**：扣库存，按移动加权记下这批货的成本（COGS）。库存不足则整单回滚。

权限：`sales:delivery`（管理员 / 老板 / 仓管）。没有销售订单权限的仓管，仍可在出库页看到可发货订单。

## 销售发票（销售 → 销售发票）

1. 选一张**已完成、还没开完票**的出库单。
2. 开票数量不能超过已发量（跨发票累计）。
3. 过账生成**应收账款**和凭证。过账前会二次确认。

权限：`sales:invoice`（管理员 / 老板 / 会计）。会计可以在发票页看到可开票出库单，不必先有出库菜单。

## 收款（销售 → 收款）

客户回款用收款单分摊到应收，过账才核销。详见财务手册。
