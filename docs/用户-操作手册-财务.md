# 操作手册 — 财务

财务不从聊天里「改一笔账」。业务过账会自动出凭证；人要做的是核对应收应付、收付款、关账和看报表。

菜单：左侧 **财务** 与 **报表**。

## 科目、资金账户、凭证

- **科目**：小企业会计准则预置科目。查询登录即可；改科目需要 `finance:account`。
- **资金账户**：收付款要用。账户必须映射到启用的末级货币科目。
- **凭证**：草稿保存时就必须借贷平衡，不平存不了。审核即过账。关账期内不能再过账。
- 已过账凭证不能删、不能改数字，只能红字冲销（借贷对调）。

## 应收应付

- 销售发票过账 → 应收。采购发票过账 → 应付。
- 到期日随客户/供应商结算方式走：现结、预付按发票日；月结按次月同日。
- **核销必须通过收付款单**，不要幻想有一个「把欠款改成已付」的独立按钮——那会做成「动子账不动总账」。

## 收款 / 付款

1. 选资金账户和对手方，按行分摊到具体应收或应付。
2. 不能跨客户/供应商乱摊，不能超额。
3. 过账同一事务里：单据完成 + 核销 + 现金凭证。任一步失败全部回滚。
4. 已经核销的发票若要冲销，必须先冲对应的收付款单。

权限：`finance:settlement`（管理员 / 老板 / 会计）。

## 账期与关账

1. 财务 → 账期关账，先跑 **关账预检**。
2. 有 ERROR 不能关（库存勾稽、借贷不平衡等）。WARN 不拦。
3. 关账会做损益结转，试算平衡后再把账期设为已关闭。
4. 关账后不能再过账。重开账期是高权限动作（`finance:period_reopen`），不要当日常改数开关。

## 报表

- 财务里的资产负债表、利润表，以及左侧 **报表** 模块的账龄、试算、进销存查询。
- 金额数量都是字符串。页签按权限隐藏，没有权限不会看到别人的经营数据。
- 需要带走时用 **导出 Excel**。

资产负债表在未关账时也会平衡（未结转损益折入未分配利润）。利润表不含关账结转凭证，否则利润会被冲成 0。
