- 文档：本文件 + `docs/部署-安全基线.md`，并从一键安装 / README / 路线图 / Q-7 链入

## 本地如何验

```bash
./deploy/install.sh --check
./deploy/upgrade.sh --check
# 有 Docker 时：
./deploy/install.sh --skip-docker-install
./deploy/restore-smoke.sh
git diff --stat -- web-dist   # 应无输出
```

聚焦后端（示例）：

```bash
cd server
mvn -B -ntp test -pl sjherp-domain -Dtest=PasswordPolicyTest,UserServiceTest
mvn -B -ntp test -pl sjherp-app -Dtest=RateLimitFilterTest,SqlLikesTest,LlmEgressServiceTest,ArchiveWritePermissionApiTest,UserAdminControllerRoleTest,AuthControllerTest
mvn -B -ntp test -pl sjherp-infra -Dtest=AesGcmSecretEncryptorTest,SensitiveSchemaGuardTest
```

前端：`cd web && npm test`

手测 HTTPS：浏览器打开安装脚本打印的 `https://.../`（自签需继续访问）；`curl -k https://127.0.0.1/api/health` 为 UP。`SJHERP_TLS_MODE=off` 时退回 HTTP。

手测出境条：配置真实 `SJHERP_LLM_API_KEY` 并重启 app 后登录聊天，应看到黄条；留空 Key 则无条、工作台仍可用。
