# ADR-004：前端组件库选型（Ant Design React）

- 状态：已采纳
- 日期：2026-10-21
- 来源：路线图 M7-T05「信息架构稳定后引入 Ant Design/Naive 之一（写 ADR），统一表格/表单/弹窗」
- 关联：`web/`（Vite + React 18 + TypeScript）、M7-T06 已落地的报表查询表

## 背景

传统工作台（档案、单据、报表）目前用手写 HTML 表格、原生 `input/select`、侧栏详情和少量 `window.confirm`。聊天主入口、登录页、深蓝侧栏已用自定义 CSS 搭稳信息架构，继续全站手写会让分页/表单/弹层行为漂移。

路线图原文对比的是 **Ant Design Vue** 与 **Naive UI**。二者都是 Vue 3 组件库。现有 `web/` 是 **React 18 + Vite + TypeScript**，不是 Vue；把前端迁到 Vue 等于整站重写，超出本刀「统一一批高频壳子、不要一次全站重写」的范围。因此在路线图两候选之外，按现有栈补评 **Ant Design React（`antd` 5）**。

## 候选对比

| 维度 | Ant Design Vue | Naive UI | Ant Design React（antd 5） |
| --- | --- | --- | --- |
| 运行时 | Vue 3 | Vue 3 | React 18（匹配 `web/`） |
| 接入成本 | 需重写全部页面 | 需重写全部页面 | 按页渐进替换 |
| 表格 | 成熟分页/筛选 | 成熟，体积更轻 | 成熟分页/空态/行事件 |
| 表单 | 校验与布局完整 | 完整 | Form + 行内筛选布局完整 |
| Modal / Drawer / Message | 有 | 有 | 有；须走 `App.useApp()` 才能吃到主题 |
| 主题 | token | TS 主题对象 | `ConfigProvider` Design Token，可对齐现有 CSS 变量 |
| 体积 | 中 | 更轻 | 中。antd 5 为 ESM + CSS-in-JS；Vite 可 tree-shake 未引用组件。本刀只从 `web/src/ui` 引用 Table/Form/Input/Select/Button/Modal/Drawer/App |
| 与现有 CSS | Vue 生态，无法共存于当前 React 树 | 同上 | hashed CSS-in-JS 与自定义 class 隔离；**不引入** `antd/dist/reset.css`，避免冲掉侧栏/聊天/登录 |

## 决策

采用 **Ant Design React 5（npm 包 `antd`）**，作为传统工作台表格、筛选表单、Modal、Drawer、Message 的唯一组件库。

不采用 Ant Design Vue / Naive UI：它们要求 Vue 运行时，与已交付的 React 工作台、权限守卫、SSE 聊天不兼容。

不引入第二套设计系统（Mantine / shadcn / Arco 等）：路线图只要「Ant Design/Naive 之一」；再加一套 token 会分裂品牌色。

## 主题与品牌色

根 token 对齐 `web/src/styles/global.css` 的 `:root`，不大改品牌色：

| Token | 取值 | 来源 |
| --- | --- | --- |
| `colorPrimary` / `colorInfo` | `#2563eb` | `--color-primary` |
| `colorError` | `#dc2626` | `--color-danger` |
| `colorTextBase` | `#1f2733` | `--color-text` / `--color-sidebar` |
| `colorBorder` | `#d9dee5` | `--color-border` |
| `colorBgLayout` | `#f5f6f8` | `--color-bg` |
| `borderRadius` | `6` | 现有按钮/输入圆角 |
| `fontFamily` | 系统中文字体栈 | `body` |

深蓝侧栏（`--color-sidebar: #1f2733`）继续用自定义 `.sidebar`，不用 antd `Layout`/`Menu` 重做导航。

启用 `theme.cssVar: true`（React 18 可用 `useId`），组件样式仍带 hash，避免全局污染。

## 与自定义 CSS 的共存策略

1. **唯一入口**：业务页不得直接 `import { Table } from 'antd'` 铺开。统一走 `web/src/ui` 薄封装（`WorkbenchTable` / `FilterBar` / `AppModal` / `AppDrawer` / `useWorkbenchNotice`）。
2. **聊天、登录、侧栏、通知铃、单据卡片保持手写 CSS**，本刀不迁。
3. **不引入 antd 全局 reset**，不覆盖 `:root` 品牌变量。
4. **渐进迁移**：本刀只改高频壳子抽样页；其余工作台仍用 `.memory-table`，后续按同一封装替换。
5. **金额/数量**：封装层 `formatAmountText` 只做空值 → `—`，原样展示后端字符串，禁止 `parseFloat` / `Number` 参与运算或展示。
6. **权限 fail-closed、错误展示 `{error}` 原文** 仍由页面自己做；组件库不改契约。

## 本刀落地范围

- 客户档案：筛选表单 + 表格 + 新建/编辑 Modal + 详情 Drawer + 成功 Message；停用走 `modal.confirm`。
- 供应商档案、仓库档案（`MasterDataWorkbench`）：筛选表单 + 表格。
- M7-T06 `QueryTable`：改为复用 `WorkbenchTable`，不改报表加载、权限、导出 Excel、图表。

## 后果

- `web/package.json` 增加 `antd@5`；生产构建会多一个 antd chunk，由 Vite ESM tree-shake 未用组件。
- 传统工作台视觉会向 antd 表格/表单靠拢，但主色仍是现有蓝，侧栏仍是深蓝。
- 未迁页面继续手写表格，允许两套壳短期共存。
- 不改 `web-dist/`、不改 `server/`、不做 M7-T07 移动适配。
