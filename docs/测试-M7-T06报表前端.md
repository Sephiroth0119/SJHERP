## 当前状态

从最新 `main`（M7-T04 多会话聊天）派生。侧边栏新增只读「报表」模块：通用查询表格（筛选 / 分页 / 导出 Excel）+ 关键图表。财务模块既有账龄、资产负债/利润表页同步补上导出与图表。金额与数量一律按后端字符串展示，前端不做 float 运算。未改 `server/`，未改预发 `web-dist/` 静态包。

## 验收范围

- 侧边栏 **报表** 对已登录用户可见（库存余额表 / 收发存汇总 REST 为登录即可）；具体报表选项按权限 fail-closed：
  - 库存余额表、收发存汇总：登录即可
  - 采购入库明细：`purchase:order`
  - 销售出库明细：`sales:order`
  - 应收/应付账龄：`finance:settlement`
  - 试算平衡、科目余额：`finance:voucher`
  - 资产负债表、利润表：`finance:report`
- 直达 hash（如 `#/reports/balance-sheet`）无对应权限时丢掉页签，不露出报表。
- 通用查询表：按报表类型切换筛选；API 有分页的走 `page/size`（展示页 20，导出按 200 拉全集）；无分页的试算/科目余额/资产负债/利润表一次展示。
- 导出 Excel：前端生成 SpreadsheetML（`.xls`），单元格 `ss:Type=String`，金额/数量保持原文字符串。
- 图表：账龄五桶条形图、利润表本期 vs 本年累计、试算 Σ借/Σ贷、资产负债结构等；全零或空串显示友好空态。条形宽度用 BigInt 标度，不把金额转 float。
- 错误展示后端 `{error}` 原文（`ApiError.message`）。
- 财务模块既有应收/应付账龄、资产负债表、利润表页保留，并同样提供导出与图表。
