# M7-T01 登录与权限前端测试说明

状态：实现完成，待分支 CI 与独立终审收口。

## 范围

- 保留既有登录页，仅补 token 生命周期安全提示与失效处理。
- `POST /api/auth/login`、`GET /api/auth/me` 增加向后兼容的 `permissions` 权限码集合；集合由后端 `RolePermissions` 真源按角色并集导出。
- 前端不复制角色到权限的矩阵，只使用后端权限码集合渲染菜单和执行体验层 hash 路由守卫；后端仍是最终授权边界。
- 未知权限码、旧缓存缺少 `permissions`、非法/过期 token 均 fail-closed；不实现 M7-T02 业务页面或 M7-T03 SSE。

## 自动化覆盖

- 后端 `RolePermissionsTest`：多角色权限码并集、稳定排序和不越权断言。
- 后端 `AuthControllerTest`：登录与 `/me` 均返回权限数组，SALES 包含 `sales:order` 且不包含 `memory:manage`。

- CI 前端 job：`npm test`、`npm run build`；本地另执行 `git diff --check`。
